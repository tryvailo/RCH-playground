# Firecrawl Agent vs Perplexity vs Google Reviews - Сравнительный анализ

## Обзор

Этот документ содержит анализ сравнения трех источников данных для секции Staff Quality Data:
1. **Firecrawl Agent** (новый функционал)
2. **Perplexity** (текущий fallback)
3. **Google Reviews** (текущий основной источник)

## Что было сделано

### 1. Добавлен метод Agent в Firecrawl Client

**Файл:** `api_clients/firecrawl_client.py`

Добавлен новый метод `agent()` который использует Firecrawl Agent API:

```python
async def agent(
    self,
    prompt: str,
    schema: Optional[Dict[str, Any]] = None,
    max_credits: Optional[int] = None
) -> Dict[str, Any]:
```

**Особенности:**
- Принимает естественный язык prompt для описания данных
- Автоматически ищет в интернете релевантные источники
- Извлекает структурированные данные согласно schema
- Возвращает JSON с извлеченными данными
- Поддерживает ограничение кредитов через `max_credits`

### 2. Создан тестовый скрипт для сравнения

**Файл:** `test_firecrawl_agent_comparison.py`

Скрипт тестирует все три источника и сравнивает результаты по:
- Количеству найденных отзывов
- Времени ответа
- Источникам данных
- Качеству данных

## Текущая архитектура получения отзывов

### Приоритет источников (из `staff_quality_service.py`):

1. **PRIORITY 1:** CareHome.co.uk reviews
2. **PRIORITY 2:** Indeed reviews (via Google Custom Search + Firecrawl scraping)
3. **PRIORITY 3:** Google Reviews (family/visitor reviews)
4. **PRIORITY 4:** Perplexity fallback (если других источников недостаточно)

### Как работает каждый источник:

#### Firecrawl Agent (новый)
- **Подход:** Автоматический поиск и извлечение
- **Преимущества:**
  - Не требует предварительного поиска URL
  - Автоматически находит релевантные источники
  - Структурированный вывод через schema
  - Может искать на множестве платформ одновременно
- **Недостатки:**
  - Динамическое ценообразование (может быть дорого для сложных запросов)
  - 5 бесплатных запусков в день (research preview)
  - Может быть медленнее (30-60 секунд)
  - Новый функционал, может быть нестабильным

#### Perplexity (текущий fallback)
- **Подход:** AI-поиск с последующим парсингом ответа
- **Преимущества:**
  - Низкая стоимость (~$0.005 за запрос)
  - Быстрый ответ
  - Хорошо работает для общих запросов
  - Уже интегрирован и протестирован
- **Недостатки:**
  - Требует парсинг текстового ответа (может быть неточным)
  - Ограничен источниками, которые Perplexity индексирует
  - Может пропустить специфические платформы

#### Google Reviews (текущий основной)
- **Подход:** Прямой API запрос к Google Places
- **Преимущества:**
  - Бесплатно (в пределах квоты)
  - Быстрый ответ
  - Высокое качество данных
  - Официальный источник
- **Недостатки:**
  - Только отзывы из Google
  - В основном отзывы от семей/посетителей, не от сотрудников
  - Ограниченное количество отзывов на странице
