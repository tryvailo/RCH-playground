## ⚠️ Проблема: 401 Unauthorized

### Причины проблемы

Companies House API возвращает **401 Unauthorized** для всех запросов. Это указывает на проблему с аутентификацией.

**Возможные причины:**

1. **API ключ неверный или истек**
   - Ключ может быть неактивным или удаленным
   - Ключ может быть неправильно скопирован

2. **IP адрес не зарегистрирован**
   - Companies House требует регистрации IP адресов в настройках приложения
   - Текущий IP адрес может быть не в списке разрешенных

3. **Приложение в режиме 'test'**
   - Приложение может быть в режиме 'test' вместо 'live'
   - В режиме 'test' доступ ограничен

4. **Неправильный тип ключа**
   - Используется Streaming API ключ вместо REST API ключа
   - Или наоборот

5. **Проблема с HTTP Basic Auth**
   - Companies House использует HTTP Basic Auth (API key как username, пустой password)
   - Возможна проблема с кодировкой или форматом

## ✅ Рекомендации по исправлению

### 1. Проверка API ключа

```bash
# Проверьте, что API ключ правильный
# Получите новый ключ на: https://developer.company-information.service.gov.uk/
```

**Шаги:**
1. Войдите в аккаунт Companies House Developer Hub
2. Проверьте статус приложения (должно быть 'live')
3. Убедитесь, что используете REST API ключ (не Streaming)
4. Скопируйте ключ и обновите в `config.json`

---

### 2. Регистрация IP адреса

**Шаги:**
1. Войдите в аккаунт Companies House Developer Hub
2. Перейдите в настройки приложения
3. Добавьте текущий IP адрес в список разрешенных
4. Сохраните изменения

**Проверка IP адреса:**
```bash
curl https://api.ipify.org
```

---

### 3. Проверка режима приложения

**Шаги:**
1. Войдите в аккаунт Companies House Developer Hub
2. Проверьте режим приложения
3. Убедитесь, что приложение в режиме 'live' (не 'test')
4. Если в режиме 'test', переключите на 'live'

---

### 4. Тестирование API ключа напрямую

```bash
# Тест с curl
curl -u "YOUR_API_KEY:" \
  "https://api.company-information.service.gov.uk/search/companies?q=test&items_per_page=1"
```

Если запрос возвращает 401, проблема в API ключе или настройках приложения.
